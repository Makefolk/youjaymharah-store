Fonts for the generated link-preview images (`lib/og`), which can't use
`next/font`. Static instances of the site's fonts from Google Fonts: Bodoni
Moda at its 36pt optical size (sturdier hairlines for small previews),
regular, and Instrument Sans regular and
medium. Neither has the naira sign, so `NotoSans-Naira-*` holds just "₦".

All are under the SIL Open Font License 1.1 (https://openfontlicense.org),
which allows bundling them with the application.
